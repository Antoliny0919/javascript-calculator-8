# **문자열 덧셈 계산기**

## 구현할 기능 목록 ✨️

- [x] 문자열 입력 받기
- [x] 기본 구분자 처리하기
  - [x] 쉼표(,)와 콜론(:)을 기본 구분자로 커스텀 구분자가 사용되지 않을때 처리
- [x] 커스텀 구분자 처리하기
  - [x] 문자열 앞부분의 "//"와 "\n"사이에 위치하는 문자를 커스텀 구분자로 처리
  - [x] 커스텀 구분자 입력관련 예외 처리
    - [x] 숫자 구분자 사용 확인
    - [x] 커스텀 문자열 구분자 사용 확인
- [x] 계산할 문자열 값 처리하기
  - [x] 구분자를 기준으로 문자열 분리하기
  - [x] 입력받은 값 관련 예외 처리
    - [x] 유효한 구분자 사용 확인
    - [x] 덧셈할 값들이 양수인지 확인
- [x] 분리된 문자를 숫자로 변환하기
- [x] 분리된 숫자를 더하여 결괏값 구하기
- [x] 결과 출력하기
  - [x] "결과 : {결괏값}" 형식으로 출력

## 테스트 케이스 추가 목록

- [x] 커스텀 구분자 입력 예외
  - [x] 숫자 구분자 사용 테스트 케이스 추가
  - [x] 문자열 구분자 사용 테스트 케이스 추가
- [x] 계산할 문자열 값 입력 예외
  - [x] 잘못된 형식의 문자열 테스트 케이스 추가
  - [x] 양수가 아닌 값 존재 테스트 케이스 추가
- [x] 유효한 입력
  - [x] 여러 구분자 사용 테스트 케이스 추가
  - [x] 커스텀 구분자와 기본 구분자 사용 테스트 케이스 추가
  - [x] 문자 커스텀 구분자 사용 테스트 케이스 추가
  - [x] 큰 숫자 사용 테스트 케이스 추가
